# 📊 Telco Müşteri Kaybı (Churn) Analizi

Bu çalışma, Telekomünikasyon sektöründeki müşteri kaybını tahmin etmek amacıyla **Orange Data Mining** aracı kullanılarak hazırlanmıştır.

## 📝 Ödev Konusu
* **Konu:** Telco Müşteri Kaybı (Churn) Tahminleme
* **Araç:** Orange Data Mining Tool
* **Yöntem:** Makine Öğrenmesi (Sınıflandırma)

## 🏗️ Kullanılan Algoritmalar
* Logistic Regression
* Random Forest
* Neural Network (Yapay Sinir Ağları)

## 📈 Analiz Süreci
1. Veri setinin okunması ve hedef değişkenin belirlenmesi.
2. Veri görselleştirme ve dağılım analizi.
3. Modellerin eğitilmesi ve Test/Score aşaması.
4. Confusion Matrix ile başarı oranlarının analizi.
